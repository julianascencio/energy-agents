Tandem-module procurement premium
====================================================================================================

On 10 November 2026, Heliene and Caelux announced commercial-scale tandem-module
production, with delivery in 2027. Their
`issuer announcement <https://www.globenewswire.com/news-release/2026/11/10/3399606/0/en/heliene-and-caelux-bring-next-generation-hybrid-tandem-solar-modules-to-u-s-commercial-manufacturing.html>`_
reports efficiency above 27% and an up-to-20% energy claim. These are manufacturer
claims, not independently verified site yields or lifetime guarantees.

A commercial rooftop owner or EPC procurement team could pay for an auditable
bid-comparison and independent-yield diligence service. The decision is the
maximum **all-in incremental installed premium**, including electrical changes,
that a constrained roof could justify. Willingness to pay and service revenue
have not been measured. This is a tender screen, not a purchase recommendation.

Run the offline example
-----------------------

.. code-block:: bash

   python -m pip install -e ".[dev,docs,quantum]"
   energy-agents-tandem --output outputs/tandem
   python examples/procurement/plot_tandem_premium.py

The packaged annual MWh arrays were actually generated by EDI, not invented
model results. Default runs need neither network nor keys nor EDI. All underlying
physical and financial inputs remain **synthetic**. JSON output preserves source,
input hash, evidence-to-finance trace and annual cash flows.

Assumptions and results
-----------------------

The same 2,000 square metres of usable module area is represented by a conventional
0.44 MW equivalent peak profile. This is not gross roof area or an engineered
layout. A 20% profile uplift is an assumed scenario, not derived from the reported
27% efficiency. Both alternatives share a 0.30 MW AC/export ceiling. Hourly
inverter-input-equivalent power follows the explicit synthetic daily/seasonal
formula in ``edi_energy``. EDI clips every one of 8,760 hours before aggregating.
Availability is a uniform 98% multiplier after clipping. No additional conversion
loss is applied. This is a simplified energy screen, not a tandem spectral model.

Twenty copies of that weather year are scaled by annual mean retention
``(1-rate)**(year-1)``: conventional 0.5%/year, tandem either 0.5% or 2%/year.
There is no leap year, first-year burn-in, repair, replacement or capacity expansion.
These trajectories are assumptions, not warranties or predictions.

Cash uses constant-real USD, year-end receipts, 7% discount rate, $100/MWh flat
energy value, $500/year extra O&M and a $50,000 incremental installed premium
at time zero. Common costs cancel. No debt, taxes, subsidies, terminal value,
time-varying tariff, counterparty risk or monetised warranty is included.

.. list-table:: Synthetic twenty-year incremental economics
   :header-rows: 1

   * - Scenario
     - Maximum premium (USD)
     - NPV after $50,000 premium (USD)
   * - 20% profile uplift, equal degradation
     - 90,235
     - 40,235
   * - 20% profile uplift, faster degradation
     - 31,290
     - -18,710
   * - No profile uplift, equal degradation
     - -5,297

Negative premium ceilings mean that even a zero premium fails to cover extra
operating cost. No probabilities are assigned. The gallery varies energy value
from $0 to $200/MWh; it also shows where faster degradation erases energy gains.
Engineering review must establish electrical compatibility, usable area, structural
loads, measured yield, clipping, degradation and enforceable warranty terms.

Reusable agent contract
-----------------------

``data/tandem/skill.json`` saves the user request, mandate, schema, allowed tools,
scheduler prompt, handoffs and acceptance criteria. The existing Project Finance
Analyst receives only validated evidence. Failed validation blocks finance; the
orchestrator rejects premature delegation and all unregistered actions. The
workflow is scripted. Its result must equal the direct deterministic calculation;
no agent superiority, live LLM execution, token usage or provider cost is claimed.
Those unmeasured values are null. Hashes detect accidental drift, not malicious
forgery or scientific truth. Neither output nor source prose authorises action.

EDI execution and provenance
----------------------------

The bounded adapter calls only
``energy_methods.pv_repowering.lifetime_intervention`` for clipped annual energy.
No scientific clipping implementation was copied. Existing lifetime methods were
inspected; no degradation fit is justified by this announcement. The focused
five-file source catalogue and execution commit are packaged beside ``case.json``.
The catalogue builder reads committed blobs and records SHA-256 and public symbols.
Discovery remains distinct from the recorded execution.

For optional replay use Python 3.12+, NumPy and pandas plus the pinned EDI package:

.. code-block:: bash

   python -m pip install --no-deps -r requirements/tandem.txt
   python -m pip install 'numpy>=2.2,<2.4' 'pandas>=2.2,<3'
   energy-agents-tandem --verify-edi --output outputs/tandem_replay

EDI is a separate dependency under LicenseRef-ASVA-Noncommercial-1.0, not this
repository's MIT license. Commercial use of that dependency requires separate
licensing review. No EDI source is vendored. The inspected environment versions
and measured one-run adapter latency are in the case provenance; this does not
establish full EDI dependency health or a performance benchmark.
