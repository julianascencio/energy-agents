Energy Agents
=============

**Agentic engineering for energy systems — created by ASVA Consulting.**

Build inspectable LLM workflows around tested engineering tools. Keep source
evidence, model edits, validation and reported outcomes separate.

The first research example explores building energy model modifications based
on Shirzadi et al. (2026). Run it offline, inspect every action, and compare local
scripted tool counts with clearly separated published observations.
